# Kugou Lite for MyGo Music

A MyGo Music plugin for searching and playing music from Kugou Concept Edition
(酷狗概念版). It talks directly to Kugou's public music endpoints; no separate
server is needed.

## Install

In MyGo Music, open **Settings → Plugins → + → Install from GitHub** and enter
`craigary/mygo-music-kugou-lite`. The plugin requests access to Kugou's music
and lyrics hosts.

## Features

- Search songs, albums, artists, and playlists
- Open chart, album, artist, and playlist pages
- Stream available song qualities, falling back when a quality is unavailable
- Load timed or plain lyrics when Kugou has them

Availability and audio quality depend on Kugou's catalog and account
restrictions. This plugin does not collect or store Kugou account credentials.
